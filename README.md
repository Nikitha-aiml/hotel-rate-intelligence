\# Hotel Rate Intelligence



Scrapes hotel room rates, stores them in a database, and serves price suggestions through a Flask API.



\## Planned stack

Python, Scrapy, Flask, SQL (MySQL), pandas, scikit-learn



\## Status

Work in progress. Started 19 Nov 2026.



\## Planned features

\- Rate scraper (Scrapy / requests + BeautifulSoup)

\- Database storage and cleaning

\- Flask REST API

\- Simple price-suggestion model
